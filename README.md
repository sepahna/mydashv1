# MyDash

داشبورد شخصی آفلاین با React Native و TypeScript (Expo).

## امکانات نسخه اول
- نمایش تاریخ شمسی عددی و نام ماه
- نمایش تاریخ میلادی عددی و ساعت دستگاه
- افزودن و حذف یادداشت سریع
- ذخیره یادداشت‌ها روی دستگاه با AsyncStorage
- رابط فارسی و راست‌چین با تم تیره

## اجرا
```bash
npm install
npx expo start
```

برای اندروید:
```bash
npx expo start --android
```

تاریخ و ساعت از تنظیمات محلی دستگاه گرفته می‌شوند. پس از نصب، برای استفاده روزمره اینترنت لازم نیست.
